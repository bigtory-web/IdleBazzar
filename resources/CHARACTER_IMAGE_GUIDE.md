# 캐릭터 이미지 제작 가이드

이 문서는 `resources/characters`에 추가할 플레이어 캐릭터의 이미지 규칙과 생성 프롬프트 기준이다.

## 1. 이미지 제작 규칙

- 용도: 64px 또는 128px에서도 바로 읽히는 2D SD 판타지 게임 유닛.
- 시점: 하늘에서 떨어지는 적을 공격하므로, 캐릭터는 화면 위쪽을 바라보는 탑다운 3/4 시점으로 제작한다.
- 비율: 약 1.5~2등신. 머리·모자·주무기가 전체 높이의 대부분을 차지하고, 몸통은 하나의 둥근 덩어리, 팔다리는 짧은 장갑·원통 형태로 단순화한다.
- 실루엣: 한눈에 직업이 구분되어야 한다. 모자, 활, 지팡이, 방패처럼 핵심 특징은 하나 또는 둘만 남기고, 캐릭터 전체를 약 10~15개의 크고 굵은 도형으로 읽을 수 있게 만든다.
- 직업성: 새 직업을 만들 때는 무기만 교체하지 않는다. 직업에 맞는 모자·상의·하의·주조색도 함께 바꾸며, 이전 직업의 복장과 장식은 재사용하지 않는다. 예: 궁수는 숲색 후드·짧은 튜닉, 총잡이는 넓은 모자·재킷, 마법사는 뾰족모자·로브처럼 직업별 실루엣을 분리한다.
- 얼굴: 눈·눈썹·입을 최소한의 큼직한 도형으로만 표현하고 코는 생략한다. 선택창의 눈은 짧은 눈썹 위에 작은 U자형 윤곽을 두고, 안쪽에 짙은 명암 한 면과 작은 하이라이트 하나만 넣어 또렷하게 표현한다. 머리카락 가닥, 속눈썹, 과도하게 큰 눈, 세밀한 표정 묘사는 사용하지 않는다.
- 선: 매우 굵고 부드러운 짙은 외곽선. 가는 선, 손가락, 주름선, 장식선은 사용하지 않는다.
- 색: 주조색 2~3개와 보조색을 포함해 최대 6~8색. 거의 완전한 평면 채색을 사용하고, 필요한 경우에도 주요 덩어리마다 넓은 그림자 면 하나만 허용한다. 광택, 셀 셰이딩, 질감 표현은 사용하지 않는다.
- 배경: 따뜻한 아이보리 단색의 둥근 사각 카드 배경을 사용한다. 캐릭터 아래에는 작은 평평한 갈색/회색 타원 그림자 하나만 둔다.
- 공통 금지: 모든 이미지에서 공격 탄환, 화살, 마법 투사체, 화염탄, 레이저, 번개 발사, 폭발, 발사 궤적, 복잡한 입자 효과를 넣지 않는다. 공격 상태도 무기·손·몸의 포즈 변화만으로 표현한다.
- 금지: 텍스트, 로고, UI, 테두리 장식, 워터마크, 복잡한 조명, 재질 질감, 사실적 해부학, 3D 렌더링, 일본 애니메이션풍 SD 캐릭터, 세밀한 머리카락·의상·갑옷·벨트 장식.

## 2. 상태 규칙

캐릭터는 아래 세 상태를 제작한다.

| 상태 | 파일명 | 표현 |
| --- | --- | --- |
| 선택창 | `<character-id>-portrait.png` | 캐릭터 선택 창에 쓸, 약간 정면을 바라보는 3/4 시점의 기본 초상/전신 이미지. |
| 아이들 | `<character-id>-idle.png` | 카메라가 높은 곳에서 내려다보는 후면 탑다운 시점. 캐릭터의 등은 화면 아래쪽, 진행/시선은 화면 위쪽을 향한 대기 포즈. 후드·머리·어깨의 윗면이 보이고 얼굴은 보이지 않거나 아주 조금만 보인다. |
| 공격 | `<character-id>-attack.png` | 아이들과 같은 후면 탑다운 시점·크기·중심을 유지한 채, 화면 위쪽으로 공격하는 포즈. 활·지팡이·손과 몸의 기울기만 바꾼다. |

- 선택창 이미지는 다른 상태보다 약간 정면을 향하게 하되, 캐릭터의 핵심 실루엣과 장비는 그대로 유지한다.
- 아이들·공격은 정면 또는 옆모습이 아니다. 화면 아래쪽에서 화면 위쪽을 향해 움직이는 유닛을 위에서 내려다보는 후면 탑다운 시점으로 만든다.
- 공격 상태는 아이들 이미지와 캐릭터의 크기, 캔버스 위치, 색상, 장비를 동일하게 유지한다. 공격 탄환이나 공격 이펙트는 사용하지 않는다.
- 생성 전 캐릭터의 영문 ID를 먼저 정한다. 예: `wizard`, `elf-archer`, `knight`.

## 3. 복사해서 쓰는 생성 프롬프트

아래 대괄호만 캐릭터에 맞게 바꾼다.

```text
초소형 SD 스타일의 2D 판타지 모바일 게임 캐릭터 한 명.

64px와 128px에서도 즉시 읽히는 약 1.5~2등신의 작고 둥근 체형. 머리와 핵심 장비가 몸보다 크고, 몸통은 하나의 둥근 덩어리, 팔다리는 아주 짧은 장갑·원통 형태다. 캐릭터 전체는 약 10~15개의 굵고 큰 도형으로만 구성한다.

캐릭터: [직업/종족/성별]. 핵심 특징은 [모자·활·지팡이·방패 등 1~2개]만 사용한다. [주조색]과 [보조색] 중심의 제한된 팔레트. 매우 굵고 부드러운 짙은 외곽선, 큼직한 그래픽 도형, 거의 완전한 평면 채색. 선택창의 눈은 짧은 눈썹과 작은 U자형 윤곽, 안쪽의 짙은 명암 한 면과 작은 하이라이트 하나로 표현하고 코는 넣지 않는다. 머리카락 가닥·손가락·의상 주름·세밀한 장식은 넣지 않는다.

상태: [선택창/아이들/공격].

[선택창이면: 캐릭터 선택 창에 쓸 이미지로, 약간 정면을 바라보는 3/4 시점의 자신감 있는 기본 포즈.]

[아이들이면: 높은 카메라가 내려다보는 후면 탑다운 게임 시점. 캐릭터의 등과 후드·머리의 윗면은 화면 아래쪽에, 진행 방향과 시선은 화면 위쪽에 둔다. 즉, 화면 아래에서 위쪽으로 이동하는 유닛을 뒤에서 내려다보는 구도다. 얼굴은 보이지 않거나 아주 조금만 보인다. 정면, 옆모습, 카메라를 향한 눈은 넣지 않는다.]

[공격이면: 아이들과 완전히 같은 후면 탑다운 시점, 캔버스 위치, 크기, 색상, 장비를 유지한다. 캐릭터는 화면 아래쪽에서 화면 위쪽을 향한다. 무기·손·몸의 기울기만 바꿔 화면 위쪽을 [무기/마법] 공격하는 포즈를 만든다. 탄환·화살·마법 투사체·이펙트는 넣지 않는다.]

캐릭터 한 명만 중앙에 작게 배치한다. 따뜻한 아이보리 단색의 둥근 사각 카드 배경, 발밑에는 작은 평평한 타원 그림자 하나. 충분한 여백.

피해야 할 요소: 공격 탄환, 화살, 마법 투사체, 화염탄, 레이저, 번개 발사, 폭발, 발사 이펙트, 사실적 신체 비율, 긴 팔다리, 일본 애니메이션풍, 과도하게 큰 반짝이는 눈, 세밀한 머리카락·의상·갑옷·벨트 장식, 손가락, 주름선, 광택, 셀 셰이딩, 재질 질감, 복잡한 조명, 3D 렌더링, 텍스트, 로고, UI, 워터마크.
```

## 4. 생성 후 저장 절차

1. 선택창 이미지를 먼저 만든다. 이어서 아이들 상태를 만들고, 아이들 이미지를 기준 이미지로 사용해 공격 상태를 만든다.
2. 선택창 이미지는 약간 정면, 아이들·공격 이미지는 화면 아래에서 화면 위를 향하는 후면 탑다운 시점을 사용한다. 각 상태에서 캐릭터 정체성, 색상, 배경색, 외곽선 굵기는 동일하게 유지한다.
3. 필요하면 최종 PNG를 128px 또는 64px로 축소해 읽기 쉬운지 확인한다.
4. 아래 경로에 캐릭터별 폴더를 만들고 PNG를 저장한다.

```text
resources/
  characters/
    <character-id>/
      <character-id>-idle.png
      <character-id>-attack.png
      <character-id>-portrait.png
```

5. 저장 전에 모든 상태에서 공격 탄환·화살·마법 투사체·발사 이펙트, 텍스트, 로고, UI, 워터마크가 없는지 확인한다.
