# 몬스터 이미지 제작 가이드

이 문서는 `resources/monsters`에 추가할 적 몬스터와 보스의 이미지 규칙 및 생성·저장 절차다.

## 1. 이미지 제작 규칙

- 용도: 하늘에서 땅으로 수직 이동하는 탑다운 슈팅 게임의 적. 64px 또는 128px에서 즉시 구분되어야 한다.
- 시점: 몬스터는 화면 아래쪽(플레이어 방향)으로 떨어지듯 이동하는 탑다운 시점이다. 세로형 적은 위에서 아래로 향하게, 넓은 보스는 아래쪽을 향해 정면이 보이게 한다.
- 비율: 약 1.5~1.8등신 또는 단순한 한 덩어리 실루엣. 큰 머리·등껍질·날개·눈 등 대표 특징을 우선한다.
- 실루엣: 몬스터 종류별 핵심 특징을 하나만 강하게 사용한다. 예: 불 딱정벌레는 주황 등껍질과 청록 날개, 번개 정령은 파란 몸체와 번개 꼬리, 보스 박쥐형은 넓은 날개와 중앙 눈.
- 선: 굵고 부드러운 짙은 외곽선. 작은 장식, 얇은 선, 복잡한 질감은 사용하지 않는다.
- 색: 주조색 2~3개, 전체 최대 6~8색. 대부분 평면 채색이며 큰 형태마다 넓은 그림자 하나와 작은 하이라이트 하나만 둔다.
- 배경: 따뜻한 아이보리 단색의 둥근 사각 카드 배경. 몬스터 아래에는 작은 평평한 갈색/회색 타원 그림자 하나만 둔다.
- 공통 금지: 모든 이미지에서 공격 탄환, 화염탄, 화살, 레이저, 번개 발사, 폭발, 발사 궤적, 복잡한 입자 효과를 넣지 않는다. 이동과 사망의 몸·눈·날개·다리 변화만으로 상태를 구분한다.
- 금지: 텍스트, 로고, UI, 워터마크, 3D 렌더링, 사실적 재질.

## 2. 상태 규칙

일반 몬스터와 보스 모두 아래 두 상태만 제작한다.

| 상태 | 파일명 | 표현 |
| --- | --- | --- |
| 이동 | `<monster-id>-move.png` | 플레이어 쪽으로 내려오는 기본 이동 포즈. 공격 연출이나 탄환은 절대 넣지 않는다. |
| 사망 | `<monster-id>-death.png` | 이동 상태의 시점·크기·실루엣을 최대한 유지한 채 사망을 표시한다. X눈, 처진 날개, 힘 빠진 다리처럼 한두 가지 변화만 사용한다. |

- 사망 상태는 가능하면 이동 형태를 그대로 유지한다. 세로형 적은 옆으로 눕히지 말고, 이동 자세에서 눈과 팔다리만 힘 빠지게 한다.
- 보스도 이동과 사망만 사용한다. 공격 상태 이미지는 만들지 않는다.
- 이동 이미지에 공격 탄환이나 발사 효과를 추가하지 않는다.

## 3. 복사해서 쓰는 생성 프롬프트

아래 대괄호만 몬스터에 맞게 바꾼다.

```text
초소형 SD 스타일의 2D 판타지 모바일 게임 적 몬스터 한 마리.

64px와 128px에서도 즉시 알아볼 수 있는 아주 단순한 탑다운 슈팅 게임 적. 몬스터는 화면 아래쪽, 즉 플레이어 방향으로 떨어지듯 이동한다. 약 1.5~1.8등신의 작고 둥근 체형 또는 하나의 큼직한 덩어리 실루엣. [세로형/가로형]의 읽기 쉬운 형태를 유지한다.

몬스터: [종류와 핵심 특징]. [주조색]과 [보조색] 중심의 제한된 팔레트. 매우 굵고 부드러운 짙은 외곽선, 큰 그래픽 도형, 평면 채색. 각 큰 형태에 넓은 그림자 면 하나와 작은 하이라이트 하나만 사용한다.

상태: [이동/사망]. [이동이면: 플레이어 방향으로 내려오는 기본 이동 포즈이며, 공격 탄환·화염·레이저·번개·발사 이펙트는 절대 넣지 않는다.] [사망이면: 이동 상태의 시점·크기·방향·실루엣을 유지하고, X눈 또는 처진 날개/힘 빠진 다리만 더해 사망을 표현한다. 세로형 몬스터는 옆으로 눕히지 않는다.]

몬스터 한 마리만 중앙에 작게 배치한다. 따뜻한 아이보리 단색의 둥근 사각 카드 배경, 아래에는 작은 평평한 타원 그림자 하나. 충분한 여백.

피해야 할 요소: 공격 탄환, 폭발, 복잡한 이펙트, 텍스트, 로고, UI, 워터마크, 사실적 해부학, 긴 팔다리, 세밀한 표면 질감, 복잡한 갑옷, 얇은 외곽선, 3D 렌더링.
```

## 4. 생성 후 저장 절차

1. 이동 상태를 먼저 만든다. 공격 탄환이나 공격 효과가 들어가면 제거하거나 다시 생성한다.
2. 이동 이미지를 기준 이미지로 사용해 사망 상태를 만든다. 종, 위치, 크기, 방향, 색상, 배경은 유지한다.
3. 사망 이미지는 이동 상태의 실루엣이 바로 보이도록 한다. 세로형 몬스터는 옆으로 눕히지 않는다.
4. 최종 PNG를 128px 또는 64px로 축소해 몬스터 종류와 사망 여부가 구분되는지 확인한다.
5. 아래 경로에 몬스터별 폴더를 만들고 PNG를 저장한다.

```text
resources/
  monsters/
    <monster-id>/
      <monster-id>-move.png
      <monster-id>-death.png
```

6. 기존 파일명을 유지한다. 이미 있는 파일을 교체할 때만 동일 파일명으로 덮어쓴다.
7. 저장 전 공격 이미지가 없는지, 이동 이미지에 탄환/발사 이펙트가 없는지, 텍스트·로고·UI·워터마크가 없는지 최종 확인한다.
