# 바자르 키우기 전투 프로토타입

10:16 세로 화면의 10칸 전투판에서 공중 몬스터를 막는 HTML/Canvas 프로토타입입니다.

작업을 이어받는 개발자는 먼저 [`DEVELOPMENT_HANDOFF.md`](DEVELOPMENT_HANDOFF.md)를 확인하세요. 확정된 전투 규칙은 [`GAME_DESIGN_HANDOFF.md`](GAME_DESIGN_HANDOFF.md)에 정리되어 있습니다.

## 실행

PowerShell에서 아래 명령을 실행한 뒤 `http://127.0.0.1:4173/`에 접속합니다.

```powershell
.\serve.ps1
```

## 공격 중심 탄환 효과 V1

- 공격 카드는 `직선탄` 또는 `유도탄` 한 가지 발사 방식을 가집니다.
- 핵심 효과는 화염, 냉기, 바람, 보호막, 산탄, 관통, 폭발, 다중시전의 8개입니다.
- 직선 관통탄은 첫 적을 조준한 뒤 세로 또는 사선의 고정 궤적으로 적을 연속 타격합니다.
- 유도탄은 지정된 목표를 추적하며, 목표가 죽으면 다른 적을 찾지 않고 사망 위치까지 이동한 뒤 소멸합니다.
- 산탄은 최대 3명의 적에게 나뉘며, 남는 탄환은 주 대상에게 55% 피해를 줍니다.
- 관통탄은 예상 관통 수가 많은 직선을 조준하고, 폭발탄은 명중 지점 주변에 직접 피해의 60%를 줍니다.
- 다중시전은 탄환을 시간차로 추가 발사하며 추가 시전은 70% 효과를 냅니다.
- 화염은 5초 동안 유지되고 재적용 시 갱신되며, 냉기는 2.4초 동안 최대 4스택까지 적용됩니다.

## 현재 상점 테스트 풀

- S: 화염총, 보급 정령, 방벽 정령
- M: 산탄포, 관통 소총, 폭발 발사기, 화염 히드라, 빙결 광선기, 탄약 구체
- L: 폭풍 군주
- 단검은 시작 지급 전용입니다.
- 첫 상점은 화염총, 보급 정령, 방벽 정령으로 고정됩니다.

## 태그와 탄약

- 태그는 `무기`, `총`, `사역마`만 사용합니다.
- 총은 크기별로 S 2발, M 3발, L 4발의 탄약을 지니며 매 웨이브 시작 시 충전됩니다.
- 한 번의 발동으로 여러 탄환을 만들어도 발동 전체가 탄약 1발을 소모합니다.
- 탄약이 없는 총은 발사하지 않습니다.
- 보급 사역마는 발동할 때 인접 총 중 탄약이 가장 적은 한 장에 1발을 장전합니다.

## 조작

- 상점 카드의 아이콘에 마우스를 올리거나 터치하면 발사 방식과 현재 효과를 확인할 수 있습니다.
- 카드 하단 구매·업그레이드 버튼으로 영입하거나 합성합니다.
- 전투판과 창고의 캐릭터에 마우스를 올리거나 터치하면 전투 중 효과와 탄약을 확인할 수 있습니다.
- 준비 단계에서 카드를 선택하고 전투판 또는 창고의 빈 칸을 눌러 이동합니다.
- 창고 오른쪽 휴지통은 선택한 전투판·창고 캐릭터를 두 번 눌러 판매합니다.
- `웨이브 시작`을 누르면 카드가 자동으로 공격합니다.
